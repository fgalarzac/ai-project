# Evidencia externa y simulaciones

`bcrp_2024_table_2_2.csv`: transcripción del cuadro 2.2, página impresa 21,
Reporte de Estabilidad Financiera, BCRP, noviembre de 2024:
https://www.bcrp.gob.pe/docs/Publicaciones/Reporte-Estabilidad-Financiera/2024/noviembre/ref-noviembre-2024.pdf

Consulta: 10 de noviembre de 2026. Cuatro filas y tres columnas contrastadas
con la extracción del cuadro completo de la fuente primaria. La descarga
HTTP local devuelve un desafío HTML y no se conserva como PDF. La tabla
se reproduce sin red y no se presenta como una descarga de balances.

Unidades: porcentaje, 9.8 significa 9.8%. Universo: sistema financiero,
no exclusivamente banca múltiple. Variable: CAR ajustada por castigos,
no mora contable ni mora mayor de 90 días. La CAR incluye vencidos,
cobranza judicial, refinanciados y reestructurados; el ajuste incorpora
castigos de los últimos doce meses. Fechas: setiembre de 2023, marzo de 2024
y setiembre de 2024. Estas observaciones no son un resultado predictivo.

Todas las demás cifras generadas son ilustrativas, sin estimación con datos
peruanos. No se recibió el panel ni los scripts separados del plan de tesis.
